# cat-tape on Comfy Cloud

Run the effect in your browser on your own Comfy Cloud account: no install, no GPU.

1. Sign in at **cloud.comfy.org**. Drag **`cat-tapes-cloud.json`** onto the canvas (or **Workflow → Open…**).
2. Click **Run**. A few minutes later the tape appears in the **save the tape** box: 10 seconds of a fluffy orange cat
   napping in the sun, with the VHS look, `PLAY >`, a date stamp and soft lofi music.
3. Want a different cat moment? Edit the long prompt text (the **CLIPTextEncode** box near the left) and Run again.

It uses only ComfyUI's built-in nodes and the official LTX-2.5 and ACE-Step 1.5 XL turbo model files, so it is a close
cousin of the local app's look: no vignette, no scanline grid, no music fade, no cassette label, no preset shelf. For
those (and the 40-second Evening Tape), run the app locally. See the main README.
